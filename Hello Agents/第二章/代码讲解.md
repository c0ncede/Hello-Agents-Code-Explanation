# `main.py` 代码讲解 —— ELIZA 风格的"心理治疗师"聊天机器人

> 本文讲解 `main.py`（85 行）。这个程序是一个经典的 **ELIZA 聊天机器人**复刻：用户输入一句话，
> 程序用**正则表达式**匹配句式，捕获关键部分，做**人称代词反转**，再套进预设的回复模板里，
> 装出一副"心理咨询师"的样子反问你。它是 1966 年 MIT 的 ELIZA 程序的现代极简版，
> 也是学习 `re` 正则库的最佳入门案例。

---

## 一、程序整体结构

```
main.py
├── 导入模块           re（正则）、random（随机选模板）
├── rules             规则库：正则模式 → 回复模板列表
├── pronoun_swap      代词转换表："i" → "you" 等
├── swap_pronouns()   把捕获到的短语做第一/第二人称互换
├── respond()         核心逻辑：遍历规则 → 匹配 → 捕获 → 转换 → 套模板
└── 主循环            读输入 → 生成回复 → 直到用户说 quit/exit/bye
```

数据流一句话概括：

```
用户输入 ──re.search 逐条试规则──▶ 匹配成功 ──group(1) 捕获──▶ 代词反转 ──format 套模板──▶ 随机回复
```

## 二、逐段讲解

### 1. 导入模块（第 1–2 行）

```python
import re        # 正则表达式库：负责"按模式匹配字符串"
import random    # 随机库：负责"从多个候选回复中挑一个"，让机器人不那么呆板
```

### 2. 规则库 `rules`（第 5–41 行）

这是一个**字典**：键是正则模式（字符串），值是若干条回复模板。

```python
rules = {
    r'I need (.*)': [
        "Why do you need {0}?",
        "Would it really help you to get {0}?",
        "Are you sure you need {0}?"
    ],
    ...
}
```

逐条拆解这些正则：

| 正则模式 | 含义 | 匹配示例 |
|---|---|---|
| `r'I need (.*)'` | 以 "I need" 开头，`(.*)` 捕获后面全部内容 | "I need help" → 捕获 `help` |
| `r'Why don\'t you (.*)\?'` | 匹配 "Why don't you ...?"，`\'` 转义单引号，`\?` 转义问号 | 捕获中间的动词短语 |
| `r'Why can\'t I (.*)\?'` | 同上，匹配 "Why can't I ...?" | |
| `r'I am (.*)'` | 匹配 "I am ..."，捕获后面的描述 | "I am sad" → 捕获 `sad` |
| `r'.* mother .*'` | 句子中任意位置出现 "mother" | 走"母亲话题"分支 |
| `r'.* father .*'` | 句子中任意位置出现 "father" | 走"父亲话题"分支 |
| `r'.*'` | **通配符兜底**：匹配任何输入（包括空串） | 前面全不中时使用 |

两个关键点：

1. **原始字符串 `r'...'`**：正则里的 `\d`、`\?` 这类反斜杠序列，如果不加 `r` 前缀，
   Python 会先把它当作普通字符串转义（比如 `'\?'` 恰好没歧义，但 `'\d'` 会变成
   `'\\d'` 依赖巧合）。统一写 `r'...'` 是正则的最佳实践。
2. **捕获组 `(.*)`**：圆括号是"捕获组"，匹配成功后可以用 `match.group(1)` 取出
   括号里匹配到的内容。这就是机器人能"听懂"你说需要什么、你是什么状态的原因——
   它不是真的听懂，而是把你说的词**原样搬进反问句**。

模板中的 `{0}` 是 `str.format()` 的占位符，运行时被捕获内容（代词转换后）替换。

### 3. 代词转换表 `pronoun_swap`（第 44–49 行）

```python
pronoun_swap = {
    "i": "you", "you": "i", "me": "you", "my": "your",
    "am": "are", "are": "am", "was": "were", "i'd": "you would",
    "i've": "you have", "i'll": "you will", "yours": "mine",
    "mine": "yours"
}
```

ELIZA 的灵魂所在：把你说的"我"变成"你"，机器人就能说出
*"Did you come to me because you are sad?"* 这样像人话的反问。
注意键全部是**小写**——这与 `swap_pronouns` 里先 `.lower()` 相呼应。

### 4. `swap_pronouns()` 函数（第 51–57 行）

```python
def swap_pronouns(phrase):
    words = phrase.lower().split()      # ① 转小写，按空白切成单词列表
    swapped_words = [pronoun_swap.get(word, word) for word in words]
                                        # ② 逐词查表：查得到就换，查不到原样保留
    return " ".join(swapped_words)      # ③ 用空格拼回一句话
```

- `dict.get(word, word)` 是惯用技巧：`word` 在表里就返回转换值，不在就返回它自己，
  一行避免写 `if word in pronoun_swap` 分支。
- 例：`"so sad"` → 无代词可换 → `"so sad"`；`"I am happy"` → `"you are happy"`。
- 局限：只按空格分词，标点会粘连（如 `"sad."` 查不到表），大小写信息全部丢失。
  对演示程序来说足够了。

### 5. `respond()` 函数（第 59–74 行）——核心逻辑

```python
def respond(user_input):
    for pattern, responses in rules.items():          # 按字典顺序逐条试规则
        match = re.search(pattern, user_input, re.IGNORECASE)
        if match:
            captured_group = match.group(1) if match.groups() else ''
            swapped_group = swap_pronouns(captured_group)
            response = random.choice(responses).format(swapped_group)
            return response
        return random.choice(rules[r'.*'])            # ⚠️ 注意：这里有一个 Bug
```

逐行说明：

| 行 | 做了什么 |
|---|---|
| `for pattern, responses in rules.items()` | 字典保持插入顺序（Python 3.7+），所以规则是**从上到下优先级递减**：具体的句式先试，兜底的 `.*` 最后 |
| `re.search(pattern, user_input, re.IGNORECASE)` | 在整句里搜索模式；`re.IGNORECASE` 让大小写不敏感（"i need" 也能匹配 "I need"） |
| `match.group(1) if match.groups() else ''` | `match.groups()` 返回捕获组元组：有组就取第 1 组，没组（如 `.* mother .*` 和 `.*`）就用空串 |
| `swap_pronouns(captured_group)` | 捕获内容做人称反转 |
| `random.choice(responses).format(...)` | 随机挑一条模板，把转换后的短语填进 `{0}` |
| `return response` | 一旦某条规则命中，立即返回，不再看后面的规则 |

### 6. 主循环（第 77–85 行）

```python
if __name__ == '__main__':
    print("Therapist： Hello！ How can I help you today?")
    while True:
        user_input = input("You: ")
        if user_input.lower() in ["quit", "exit", "bye"]:
            print("Therapist: Goodbye. It was nice talking to you.")
            break
        response = respond(user_input)
        print(f"Therapist: {response}")
```

- `if __name__ == '__main__'`：只有直接运行 `python main.py` 才进入聊天循环，
  被 `import` 时不执行，方便别的模块复用 `respond` 等函数。
- `while True` 无限循环，靠 `break` 退出；退出词忽略大小写。
- f-string `f"Therapist: {response}"` 把回复插值输出。

## 三、走一遍完整例子

假设用户输入：**`I need help`**

1. `respond("I need help")` 开始遍历，第一条规则 `r'I need (.*)'` 就命中；
2. `match.group(1)` → 捕获 `"help"`；
3. `swap_pronouns("help")` → 无代词，原样返回 `"help"`；
4. `random.choice(...)` 随机选中 `"Why do you need {0}?"`；
5. `.format("help")` → `"Why do you need help?"`；
6. 打印 `Therapist: Why do you need help?`。

再假设输入：**`I am sad because of my mother`**

- 第一条 `I need (.*)` 不中。若 Bug 修复后，会继续试到 `r'.* mother .*'` 命中
  （该规则无捕获组），回复母亲话题的模板，例如
  *"Tell me more about your mother."*。

## 四、涉及的正则知识点回顾

| 本代码用到的 | 说明 |
|---|---|
| `re.search(p, s)` | 在 `s` 全文找第一处匹配（对比 `re.match` 只从头匹配） |
| `(.*)` | 捕获组：`.` 任意字符，`*` 重复 0 次或多次； Greedy 贪婪匹配 |
| `match.group(1)` / `match.groups()` | 取第 1 个捕获组 / 取全部捕获组组成的元组 |
| `re.IGNORECASE` | 忽略大小写标志 |
| `r'...'` | 原始字符串，防止反斜杠被 Python 提前转义 |
| `\'`、`\?` | 转义字面意义上的单引号和问号（`?` 本身是量词，需转义） |

## 五、⚠️ 这段代码有一个隐藏 Bug

`respond()` 里的兜底返回**缩进错了**：

```python
        if match:
            ...
            return response
        return random.choice(rules[r'.*'])   # ← 缩进在 for 循环体内
```

它和 `match = re.search(...)` 同级，也就是在 `for` 循环**内部**。后果是：
**只要第一条规则 `I need (.*)` 没匹配上，循环第一轮就直接返回通配符回复**，
后面的规则（`Why don't you`、`I am`、`mother`、`father` 等）永远不会被尝试。
代码注释写的"如果没有匹配任何特定规则，使用最后的通配符规则"的意图完全没有实现。

**修复方法**：把这行移出 `for` 循环，与 `for` 对齐——

```python
def respond(user_input):
    for pattern, responses in rules.items():
        match = re.search(pattern, user_input, re.IGNORECASE)
        if match:
            captured_group = match.group(1) if match.groups() else ''
            swapped_group = swap_pronouns(captured_group)
            response = random.choice(responses).format(swapped_group)
            return response
    return random.choice(rules[r'.*'])       # ← 循环全部试完仍未命中，才走兜底
```

顺带一提：因为通配符 `.*` 能匹配任何字符串（包括空串），修复后这个兜底行
实际上也永远轮不到执行——`.*` 一定会命中。它更多是"意图声明"，保留或删除皆可。
真正生效的优先级兜底靠的就是字典中 `.*` 排在最后。

## 七、可以怎么改进（练手方向）

1. **修复第五节的缩进 Bug**，观察 `mother`/`father` 话题被正确触发。
2. **加更多规则**：如 `r'Do you (.*)'`、`r'I feel (.*)'`、`r'I can\'t (.*)'`。
3. **修复代词处理的粗糙点**：用 `re.sub(r'[^\w\s]', '', phrase)` 先去标点再查表。
4. **支持多条命中**：不返回第一条，而是按"规则特异性"打分选最佳匹配。
5. **记忆功能**：把用户早先说的 `my mother` 存下来，之后追问 *"Earlier you mentioned your mother."*（原版 ELIZA 的经典技巧）。
6. **别把捕获内容直接塞进 `format`**：若用户输入里含 `{}` 会抛 `KeyError`/`IndexError`，
   更稳妥的写法是模板用 `%s` + `%`，或先转义花括号。

## 八、一句话总结

这个 85 行的小程序演示了"**模式匹配 + 模板填充**"这一最古老也最经典的对话系统范式：
`re` 负责"听出句式"，捕获组负责"摘出关键词"，代词反转负责"把话还给你"，
`random` 负责"让回应不至于千篇一律"。它完全不理解语义，却能在短短几句对话里
显得"善解人意"——这正是 1966 年 ELIZA 给整个 NLP 领域上的第一课。
